# Freight Rate Prediction - ML Engineer Assessment

## Overview
This repository contains the solution for the Freight Rate Prediction Challenge. The objective is to predict freight load rates based on historical shipping data. The end-to-end machine learning pipeline, including exploratory data analysis, data cleaning, feature engineering, and inference, is developed using LightGBM and provided as a Google Colab Notebook. A serialized version of the trained model is also included.

## Setup and Run Instructions

### 1. Clone and Initialize

Clone the repository and set up a virtual environment locally to ensure dependency isolation for the scoring script.

```bash
git clone https://github.com/AnshulKumar79/Freight_Rate_Prediction.git
cd Freight_Rate_Prediction
python -m venv venv

```

Activate the virtual environment:

* **Windows:** `.\venv\Scripts\activate`
* **macOS/Linux:** `source venv/bin/activate`

### 2. Install Requirements

Install the necessary Python packages using the provided requirements file:

```bash
python -m pip install -r requirements.txt

```

### 3. Generate Predictions (Model Execution)

The complete workflow is documented in `EDA_&_model_training.ipynb`. You can execute this notebook locally or via Google Colab to generate the required prediction files.

**Running Locally (Recommended):**

1. Open `EDA_&_model_training.ipynb` using Jupyter Notebook, JupyterLab, or VS Code.
2. Ensure your active kernel is set to the `venv` created in step 1.
3. Execute all cells sequentially. The notebook will automatically load `data/train_test.csv`, process the data, utilize the provided `model.joblib` (or retrain if specified), and output the updated `validation_predictions.csv` and `data/december_chart_inputs.csv` files.

**Running via Google Colab:**
If executing via Google Colab, upload the repository files to your Google Drive and mount the drive within the notebook. Ensure the base file paths in the notebook are updated to reflect your Colab directory structure before executing the cells.

### 4. Run the Evaluation Scorer

Once the prediction files are generated by the notebook, run the provided scoring script from your local terminal to validate the outputs and generate the December forecast chart:

```bash
python score.py --predictions validation_predictions.csv --december-predictions data/december-chart-inputs.csv

```

Upon successful execution, the script will generate `scorer_results/candidate_december.png`.
